- **`OrgSpace-Apps/`** — backend Spring Boot + app Android: [`OrgSpace-Apps/AGENTS.md`](OrgSpace-Apps/AGENTS.md)
- **`OrgSpace-Website/`** — portal web Next.js (`orgspace.com`): [`OrgSpace-Website/AGENTS.md`](OrgSpace-Website/AGENTS.md)
- **`OrgSpace-Hosting/`** — tempat web user nebeng Next.js (`orgspace.app/[namawebuser]` / `:3001`): [`OrgSpace-Hosting/AGENTS.md`](OrgSpace-Hosting/AGENTS.md)

Satu perubahan sebaiknya hanya menyentuh satu folder. Jaga pemisahan tegas antara portal korporat (`OrgSpace-Website`) dan hosting website publik pengguna (`OrgSpace-Hosting`).
